## Defects found and fixed
1. **Select primitive never reached Livewire.** `adminSelect.choose()` dispatched its `input` event on `this.$el.querySelector(...)`, but inside an Alpine method `$el` is the clicked option, so the hidden input was never found. Every `wire:model` select (grant plan, audit filters, currency) kept its old value server-side. Fixed in `Assets/admin.js` (`$root`, and the hidden value is set before the event).
2. **Grant with no plan chosen answered 500** (empty id reached a UUID column). `confirmGrant` now refuses a non-UUID plan with the "can't be granted" field error; test added.
3. **Account page showed raw keys** (`admin::accounts.plan.features.sharing.enabled`): dotted capability keys cannot be looked up in a language file. The view now uses the existing `plans.capabilities.*` keys; the dead dotted keys were removed; regression assertion added.
4. **Claim queue tabs overflowed the page at 390 px** in Arabic. The underline tabs now scroll inside their own row.

## Not covered in the browser
Keyboard-only pass, focus trapping and restoration (primitive-level behaviour from spec 006), the second-operator bell, concurrent plan editing in two tabs (stale version), the 30 per 10 minutes lookup budget and 50-per-page audit paging at volume. All have Livewire or feature tests.
