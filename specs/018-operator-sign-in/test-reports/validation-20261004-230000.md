## Fixes made during validation

- F1 `Assets/admin.js`: a Livewire update morphed an open modal `<dialog>` closed, so a wrong factor code (or any server-side validation error inside a dialog) hid itself. A `morph.updating` hook now keeps open dialogs open.
- F2 `Views/components/shell/sidebar.blade.php`: sign-out button lacked the contract's `data-test="sign-out"`.
