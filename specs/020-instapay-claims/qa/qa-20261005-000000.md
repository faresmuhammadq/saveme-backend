The admin receipt route was also driven in a browser (see `test-reports/`).

**Environment**: Fedora Linux 44 host; `dev` container PHP 8.5, PostgreSQL 16, Mailpit; the five 2026_10_09 migrations applied; throwaway operator `qa020-op@example.test` (enrolled through the browser, deactivated afterwards).

## Failures Detail
None in the product. Notes:
- Audit details omit null members (repo convention for every detail); spec and data model wording ("reason: null") was corrected to match.
- The browser console shows CSP errors on the receipt page: Chrome's own image viewer styles are blocked by `default-src 'none'`; the image still renders. Intended.
- `ios` never reaches the claim endpoint: the shared runtime rejects it with 400 CLIENT_VERSION_INVALID (Android-only MVP).
