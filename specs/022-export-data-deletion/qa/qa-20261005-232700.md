## Failures Detail
None in the feature. Test bug: AuditLogTest "records one audit_read..." hard-coded `2026-09-29`..`2026-10-05` and compared a Cairo date with a UTC clock; now computed from `config('admin.timezone')`.

Notes (not defects):
1. Member-name re-stamp runs as a queued job (`RestampMemberNames`) and, with a real worker, runs after the purge job has tombstoned the memberships, so it re-stamps 0 wallets. `ProfileUpdated` is still published before any tombstone, and partners receive the membership as a tombstone with no name, so no name remains on any feed.
2. A transferred wallet's other editors are demoted to viewer when the new owner is on the Free plan (existing demotion rule, P-09 rule 4).
3. `GET /exports?limit` follows the shared pagination parameter (clamped, `meta.limit` reports it); the contract page text now says so.
4. Link signatures are per-second: two reads in the same second return the same URL.

All 28 throwaway accounts purged by `identity:purge-accounts` (husk rows remain, audit rows left). Throwaway operator `qa022-op@example.test` deactivated.
