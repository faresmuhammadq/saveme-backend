# QA Report: Categories (spec 011, B5)

**QA Mode**: CLI QA (HTTP via curl against the running dev app; database state through `dev tinker`)
**Date**: 2026-10-02
**Feature**: [spec.md](../spec.md)
**Environment**: Fedora Linux 44 (kernel 7.2.7) host, `dev` container with PHP 8.5.10 and PostgreSQL 16, Laravel 13, http://saveme-backend.test/api/v1
**Verdict**: ✅ ALL PASSED

---

## QA Summary

All eight category operations were exercised against the live dev stack. The dev database was migrated and seeded first (`dev migrate`, `dev db:seed`), so the 26-entry platform set existed. Four fresh people were created through the app's own `UserFactory` in `dev tinker`: A (verified owner), B (verified, made an editor of A's wallet W), C (verified non-member, later a viewer of a second wallet) and U (unverified). Each signed in through `POST /auth/login`.

Memberships were inserted directly under the wallet scope sequence, as spec 010 QA did, because invitations arrive in B9. References were published by calling `CategoryReferences::publish()` inside a transaction after share-locking the category row. That is B6's call in B6's lock order, made by hand, because no HTTP path publishes before B6.

Coverage:
- every acceptance scenario of US1–US4;
- the spec's edge cases and the contract's field-level codes (`IMMUTABLE_FIELD`, `OUT_OF_RANGE` for blank and 51-character names, `UNKNOWN_FIELD` for `user_id`, `system_key`, `in_use`, `parent_id`, `archived_at`, `change_seq` and `deleted_at`, and `REQUIRED` for a DELETE with no body);
- the collection grammar;
- `405` with `Allow: GET` on the read-only paths;
- the wallet-deletion cascade;
- five concurrent stale PATCHes (exactly one lands).

US3·3 (`409 CATEGORY_IN_USE`) has **no HTTP path before B6**. No `CategoryUsage` participant is registered, so every category is unused. It is evidenced by the suite, which binds a stub participant: `tests/Feature/Wallets/Categories/DeleteCategoryTest.php` and `tests/Contract/Wallets/Categories/DeleteCategoryTest.php`.

Result: 113/113 checks passed on the first run, and no defects were found.
